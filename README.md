
# ☕ Brew & Bean

Brew & Bean is a responsive coffee shop website developed using HTML, CSS, and JavaScript.

## Project Features

- Responsive design for desktop and mobile devices
- Interactive coffee menu with search functionality
- Special offers page
- Customer reviews and star ratings
- Rewards and loyalty points system
- Contact form with input validation
- Demo login and sign-up pages
- Back-to-top button

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Website Pages

- Home
- About Us
- Menu
- Offers
- Reviews
- Rewards
- Contact Us
- Login
- Sign Up
